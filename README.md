# Designer Móveis Planejados Sá — MVP comercial

Primeira versão da landing page comercial pensada para facilitar a jornada:

**descoberta → confiança → ambientes → qualificação → WhatsApp**

## O que já funciona

- Site responsivo / mobile-first
- Navegação enxuta
- CTA único de orçamento
- Portfólio por ambiente
- Processo em 4 etapas
- Formulário de qualificação em 4 passos
- Geração automática de mensagem estruturada no WhatsApp
- CTA fixo no celular
- Instagram e contato comercial
- Identidade visual inspirada na marca pública da Designer Sá

## Rodar

Basta abrir `index.html` no navegador.

Para servir localmente:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
